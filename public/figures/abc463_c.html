ABC463 C - Tallest at the Moment

問題ページ

これは有志による非公式の解説です。内容はすべて Claude Code が出力しています。

問題

N 人の身長 H と退出時刻 L が与えられます。L は小さい順に並んでいます。各クエリ T について、T + 1/2 分後に部屋に残っている人の最大身長を答えます。

T + 1/2 分後に部屋にいるのは、L > T の人です。N と Q は最大 3×105 なので、クエリごとに全員を見ていては間に合いません。

考え方

自分より背が高く、かつ自分より遅くまで残る人がいれば、その人は答えになりません。そういう人を先に除くと、残った人は身長が大きい順、退出が遅い順に並びます。

この並びなら「まだ部屋にいる人のうち先頭の人」が最大身長なので、二分探索で求められます。計算量は O(N + Q log N) です。

動かして確認する

入力例1を使います。棒の高さが身長で、下の数字が退出時刻 L です。
