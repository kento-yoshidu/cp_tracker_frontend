ABC166 D - I Hate Factorization

問題ページ

非公式解説です。内容はすべて Claude Code が出力しています。

問題の要約

整数 X が与えられます（1 ≤ X ≤ 109）。A5 − B5 = X となる整数の組 (A, B) を 1 つ求める問題です。答えが存在することは保証されています。

考え方

A と B の候補を両方とも全部試します。問題は「どの範囲を試せばいいか」です。

隣り合う整数の 5 乗の差 n5 − (n − 1)5 は、n が大きくなるほど広がります。下の表のとおり、n = 120 で 109 を超えます。A が 120 くらいより大きいと、B をどう選んでも A5 − B5 は X を飛び越えてしまいます。なので、答えの A, B は絶対値が 120 くらいまでに収まります。

余裕をもって A, B を −1000〜1000 で試せば確実です。2001 × 2001 ≈ 4 × 106 通りなので間に合います。10005 = 1015 なので、64bit 整数でオーバーフローもしません。

動かして確認する

入力例1（X = 33）を使います。図にするため、A, B の範囲を −3〜3 に縮めています。マスの数字が A5 − B5 です。A を 1 つ決めるごとに、B を −3 から順に試します。
