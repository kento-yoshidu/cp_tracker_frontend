鉄則本 A42 - Soccer

問題ページ

非公式解説です。内容はすべて Claude Code が出力しています。

問題の要約

N 人の生徒がいて、生徒 i の体力は Ai、気力は Bi です。何人かを選んで、次の 2 つを満たすようにします。

  • 選んだ生徒の体力の最大と最小の差が K 以下
  • 選んだ生徒の気力の最大と最小の差が K 以下

最大で何人選べるかを求める問題です。体力・気力は 1 以上 100 以下です。

考え方

1. 「誰を選ぶか」ではなく「範囲」を決める

どの生徒を選ぶかをそのまま考えると、選び方は 2N 通りあって全部は試せません。

そこで見方を変えて、体力の範囲を先に決めてしまいます。例えば K = 30 で「体力が 20 以上 50 以下の生徒だけ選ぶ」と決めれば、選んだ生徒同士の体力の差は必ず 30 以下になります。この範囲に入る生徒は全員選んで問題ありません（人数が多いほど得なので）。

2. 体力と気力、両方の下限を全部試す

気力も同じように考えます。

  • 体力の下限を x に決める → 体力が x 以上 x + K 以下
  • 気力の下限を y に決める → 気力が y 以上 y + K 以下

この両方を満たす生徒を全員選べば、条件を満たします。図で言うと、体力を横軸・気力を縦軸にしたときに、一辺 K の正方形に入る生徒を選ぶことになります。

どの (x, y) が一番いいかは分からないので、x も y も 1〜100 を全部試します。

for x in 1..=100 {
    for y in 1..=100 {
        // x <= a[i] <= x + k かつ y <= b[i] <= y + k の生徒を数える
        ans = ans.max(calc(n, k, x, y, &a, &b));
    }
}

3. 計算量

(x, y) の組は 100 × 100 = 104 通りで、それぞれ N 人を調べます。N ≤ 300 なので、全体で 104 × 300 = 3 × 106 回程度で、十分間に合います。

動かして確認する

入力例1（N = 4, K = 30）を使います。プログラムは x, y を 1〜100 すべて試しますが、ここでは表示を短くするため、x, y が生徒の体力・気力のどれかと等しい組だけを順に見せます。
