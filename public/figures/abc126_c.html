ABC126 C - Dice and Coin

問題ページ

非公式解説です。内容はすべて Claude Code が出力しています。

問題の要約

1〜N の目が等確率で出るサイコロを 1 回振り、出た目を得点にします。得点が 1 以上 K − 1 以下の間はコインを投げ続け、表なら得点が 2 倍、裏なら得点が 0 になって終わります。得点が K 以上になったら勝ちです。勝つ確率を求める問題です。

考え方

サイコロの目を 1〜N まで全部試します。N ≤ 105 なので間に合います。

目を 1 つ決めると、K 以上になるまでに必要な表の回数が決まります。途中で 1 回でも裏が出たら負けなので、勝つのは必要な回数だけ連続で表が出たときだけです。回数を c とすると、その目で勝つ確率は (1/2)c です。最初から目が K 以上なら c = 0 で、確率は 1 です。

どの目も確率 1/N で出るので、答えは目ごとの確率をすべて足して N で割った値です。1 つの目につき 2 倍をくり返すのは log K 回程度なので、計算量は O(N log K) です。

動かして確認する

入力例1（N = 3, K = 10）を使います。
