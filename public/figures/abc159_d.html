ABC159 D - Banned K

問題ページ

非公式解説です。内容はすべて Claude Code が出力しています。

問題の要約

N 個のボールに整数 Ai が書かれています。k = 1, 2, …, N のそれぞれについて、k 番目のボールを除いた N − 1 個から、同じ数が書かれた 2 つを選ぶ方法が何通りあるかを答える問題です。

考え方

c 個のボールから 2 つ選ぶ方法は c × (c − 1) / 2 通りです。k ごとに、残ったボールを値ごとに数え直してこの式を足せば答えが出ます。ただし、1 回の数え直しに O(N) かかり、それを N 回行うので O(N2) です。N ≤ 2 × 105 では間に合いません。

ここで、k 番目を除いて個数が変わるのは、Ak と同じ値だけだと気づくのがポイントです。ほかの値のペア数は変わりません。

そこで、まず全体のペア数 S を 1 回だけ求めておきます。k ごとに、値 Ak の分だけ差し替えます。値 Ak のボールが全体で c 個あるとすると、次のようになります。

  • 除く前の、値 Ak どうしのペア数：c × (c − 1) / 2
  • 除いたあと（c − 1 個になる）のペア数：(c − 1) × (c − 2) / 2　← 「c 個から 2 つ」の式の c に c − 1 を入れたもの

答え ＝ S − c × (c − 1) / 2 ＋ (c − 1) × (c − 2) / 2

例：A = [1, 1, 2, 1, 2] で 1 番目（値 1）を除く場合を考えます。値 1 のペアは (1番, 2番)・(1番, 4番)・(2番, 4番) の 3 通りです。1 番がいなくなると (2番, 4番) の 1 通りだけが残ります。式でも 3 × 2 / 2 = 3、2 × 1 / 2 = 1 となり、一致します。

値ごとの個数は HashMap で数えるので、c は O(1) で取れます。全体の計算量は O(N) です。
