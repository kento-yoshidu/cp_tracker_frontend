ABC330 D - Counting Ls

問題ページ

非公式解説です。内容はすべて Claude Code が出力しています。

問題の要約

N × N のマス目があり、各マスは o か x です。次の条件をすべて満たす3 マスの組が何通りあるかを求める問題です。

  • 3 マスとも o
  • ちょうど 2 マスが同じ行にある
  • ちょうど 2 マスが同じ列にある

N ≤ 2000 なので、3 マスを全部試す O(N6) は間に合いません。

考え方

1. 3 マスは必ず「L 字」になる

条件を満たす 3 マスを並べると、必ず次のような L 字になります。

A . . B      ← A と B が同じ行
. . . .
C . . .      ← A と C が同じ列

A は「B と同じ行」かつ「C と同じ列」にある角（かど）のマスです。1 つの組に角はちょうど 1 つなので、どのマスを角にするかで場合分けすれば、二重に数えることも数え漏らすこともありません。

2. 角を (i, j) に決めたときの選び方

行 i にある o の数を w[i]、列 j にある o の数を h[j] とします。角 A = (i, j) が o のとき、

  • B は行 i の、A 以外の o → w[i] − 1 通り
  • C は列 j の、A 以外の o → h[j] − 1 通り

B と C は別々に選べるので、角が (i, j) の組は (w[i] − 1) × (h[j] − 1) 通りです。

3. 全マスで足し合わせる

先に w と h を数えておき、o のマスすべてについて上の式を足せば答えです。

for i in 0..n {
    for j in 0..n {
        if s[i][j] == 'o' {
            ans += (w[i] - 1) * (h[j] - 1);
        }
    }
}

計算量は O(N2) です。答えは最大で N2 × (N − 1)2 ≒ 1.6 × 1013 程度なので、64bit 整数を使います。

4. 注意：w と h を取り違えない

正方形のマス目でも、w[i]（i 行目の個数）と h[i]（i 列目の個数）は別の場所の個数です。s[i][j] は「行 i・列 j」なので、使うのは w[i] と h[j] です。

入力例1で (h[i] − 1) × (w[j] − 1) と書いてしまうと、右上のマス (0, 2) が 2 ではなく 0 と数えられ、答えが 4 ではなく 2 になります。
