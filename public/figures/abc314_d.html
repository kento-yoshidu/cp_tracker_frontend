ABC314 D - LOWER

問題ページ

非公式解説です。内容はすべて Claude Code が出力しています。

問題の要約

長さ N の英字の文字列 S に、Q 個のクエリを順に行います。クエリは次の 3 種類です。

  • t = 1：x 文字目を文字 c に変える
  • t = 2：すべての大文字を小文字にする
  • t = 3：すべての小文字を大文字にする

すべてのクエリを行ったあとの S を出力する問題です。

考え方

t = 2, 3（一括変換）のたびに全文字を書き換えると、1 回 O(N) で全体 O(NQ) になり、間に合いません。

ポイントは、一括変換は全文字の大文字・小文字を上書きすることです。そのため、最後の一括変換より前の一括変換は結果に残りません。覚えておくのは「最後の一括変換がいつ（last）で、大文字・小文字のどちらか（flag）」だけで十分です。

一方、t = 1 の個別の変更は、文字列 s にそのまま書き込みます。そして、文字ごとに最後に個別の変更を受けた時刻 v[x] を覚えておきます。

最後に、文字ごとに次のように判定します。

  • v[x] < last：最後の一括変換より前に書かれた文字なので、一括変換（flag）を適用する
  • v[x] ≥ last：最後の一括変換より後に書かれた文字なので、そのまま出力する

どのクエリも O(1)、最後の判定が O(N) なので、全体で O(N + Q) です。
