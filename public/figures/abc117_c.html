ABC117 C - Streamline

問題ページ

これは有志による非公式の解説です。内容はすべて Claude Code が出力しています。

問題の要約

数直線上に N 個のコマを好きな位置に置き、1 ずつ動かして M 個の座標 X をすべて訪れます。必要な移動回数の最小値を求める問題です。正確な条件は問題ページを確認してください。

考え方

まず X をソートします。1 つのコマがひとまとまりの点を回るとき、左端に置いて右へまっすぐ進めばよいので、移動距離は右端 − 左端です。これは、その範囲の隣どうしの差の合計と同じです。

点をグループに分けると、境目の差だけは誰も歩かなくなります。なので、移動距離の合計は「全部の差の合計 − 境目にした差」になります。

全部の差の合計は区切り方に関係なく決まっています。N 個のグループに分けると境目は N − 1 か所なので、大きい差から N − 1 個を選んで引けば最小になります。N ≥ M なら全部の点にコマを置けるので、答えは 0 です。計算量は O(M log M) です。

動かして確認する

入力例1（N = 2, X = 10, 12, 1, 2, 14）を使います。数直線上の線の数字が、隣どうしの差です。
