ABC484 C - Move One Card

問題ページ

非公式解説です。内容はすべて Claude Code が出力しています。

問題の要約

長さ N の列 A と B が与えられます。A から要素を 1 つ取り出し、好きな位置に入れ直す操作をちょうど 1 回行います。操作後に A を B と一致させられるかを判定する問題です。

取り出した要素を元の位置に戻してもよいので、A と B が最初から同じなら Yes です。

考え方

1. 1 枚動かすと何が起きるか

例えば [1, 2, 3, 4, 5] の 2 を取り出して 4 の後ろに入れると、次のようになります。

位置:    0  1  2  3  4
操作前:  1  2  3  4  5
操作後:  1  3  4  2  5
         ○  ×  ×  ×  ○

変わるのは「取り出した位置」から「入れた位置」までだけで、その外側は全く変わりません。

2. 調べる区間をしぼる

そこで、A と B を左から比べて最初に違う位置を left、右から比べて最初に違う位置を right とします。違いは区間 [left, right] の中にしかありません。

3. 試す操作は 2 通りだけ

動かしたカードは区間の端から端へ移動したはずなので、次の 2 通りだけ試せば十分です。

  1. a[left] を取り出して、位置 right に入れる（左端 → 右端）
  2. a[right] を取り出して、位置 left に入れる（右端 → 左端）

どちらかで B と一致すれば Yes、どちらもダメなら No です。

4. 同じ数字があっても大丈夫な理由

同じ数字があると、実際に動かしたカードが区間の外にはみ出していることがあります。

A = [1, 1, 2]   a[0] の 1 を末尾へ動かすと
B = [1, 2, 1]   B になる。でも left = 1

位置 0 は 1 と 1 で同じに見えるので、left は 1 になります。でも、a[1]（= 位置 left）の 1 を末尾へ動かしても同じ B になります。a[0] と a[1] が同じ数字なので、どちらを取り出しても残る列は同じだからです。

入れる位置が right より右にはみ出す場合も同じで、隣に同じ数字があるので位置 right に入れても結果は変わりません。

A = [1, 2, 1]   a[0] の 1 を末尾（位置 2）へ動かすと
B = [2, 1, 1]   B になる。でも right = 1
→ 位置 1 に入れても [2, 1, 1] で同じ

つまり、はみ出した操作があっても left と right の操作で代わりがきくので、2 通りで見逃しません。

5. 計算量

実装では、A をコピーして remove と insert で実際に操作した列を作り、B と比べます。どれも O(N) で、2 回やるだけなので全体で O(N) です。
